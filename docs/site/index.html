🔬 المختبر والدليل

16 حساسًا: ماذا يقيس كل حساس، وكيف يعمل، وفوائده، وأي الأجهزة تدعمه. جرّب كل حساس مع رسم بياني حيّ.

🧭 «رفيق»

تطبيق واحد يستخدم كل الحساسات: اتجاه القبلة، والمسبحة بالتلويح، ونشاطي اليومي، وبيئة القراءة، والميزان، والعدسة المكبّرة، مقفل ببصمتك.

📱 أفضل الأجهزة

ترتيب الجوالات المشهورة بحسب أهم الحساسات، مع درجة جوالك أنت، ولكل حساس قائمة الأجهزة التي تضمّه.

🛡️ فاحص التطبيقات

يعطي كل تطبيق في جوالك درجة أمان من 100: مصدر التثبيت، والتوقيع، والصلاحيات القوية، والأجزاء المكشوفة، والمفاتيح السرية المسرّبة في كوده.

الأمان والخصوصية

  • التطبيقان لا يملكان إذن الإنترنت أصلًا، فلا يمكن أن تخرج أي قراءة من جوالك.
  • لا يُحفظ شيء: لا قراءات ولا صور ولا صوت. الميكروفون يقيس شدة الصوت فقط.
  • الأذونات تُطلب عند فتح الميزة فقط مع شرح السبب، و«فاحص التطبيقات» بلا أي إذن.
  • كل الحساسات تتوقف فور خروجك من التطبيق.
  • كل تعديل يُفحص آليًا بأداة mvscan (الكود وملف APK الناتج) قبل نشره.

للمطوّرين: mvscan

أداة Python بلا مكتبات خارجية تفحص مشاريع أندرويد وiOS وFlutter وReact Native، وملفات APK وIPA، والتطبيقات المثبتة عبر USB. فيها أكثر من 55 قاعدة، وتصدر تقارير نصية وJSON وHTML وSARIF.

python3 -m mvscan app.apk --format html -o report.html
