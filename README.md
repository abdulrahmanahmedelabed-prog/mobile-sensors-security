# حساسات الجوال والأمان

مشروع تعليمي وعملي من ثلاثة أجزاء:

1. **دليل حساسات الجوال**: 16 حساسًا، ولكل حساس شرح لما يقيسه وكيف يعمل وما فوائده، مع **تطبيق بسيط** لتجربته.
2. **«رفيق»: تطبيق شامل يستخدم جميع الحساسات**، ويوضّح أي حساس يُستخدم وفي أي جزء من التطبيق.
3. **mvscan: كاشف الثغرات البرمجية** في تطبيقات الجوال، سواء من كودها المصدري أو من ملفات APK/IPA،
   أو مباشرة من التطبيقات المثبتة في جوالك.

البرنامج مكتوب مع مراعاة الأمان (راجع [الأمان في تطبيق الحساسات](#الأمان-في-تطبيق-الحساسات))، ويُفحص كل
تعديل عليه آليًا بأداة الثغرات نفسها قبل بنائه.

## 1) دليل الحساسات: الفوائد والتطبيق البسيط لكل حساس

| الحساس | ماذا يقيس | أهم فوائده | التطبيق البسيط |
|---|---|---|---|
| مقياس التسارع (Accelerometer) | التسارع على X و Y و Z (م/ث²) | تدوير الشاشة، واكتشاف الهزّ والسقوط، وعدّ الخطوات، والألعاب | **عدّاد الهزّات** |
| الجيروسكوب (Gyroscope) | سرعة الدوران (راديان/ث) | تثبيت الفيديو، والواقع الافتراضي، وصور 360°، ودقة البوصلة | **مؤشر الدوران** |
| المغناطيس (Magnetometer) | المجال المغناطيسي (µT) | البوصلة، والقبلة، وكشف المعادن، وغطاء الجوال | **كاشف المعادن** |
| متجه الدوران (Rotation vector) *برمجي* | اتجاه الجوال الكامل في الفراغ | بوصلة ثابتة، والواقع المعزّز، والخرائط | **البوصلة** |
| الجاذبية (Gravity) *برمجي* | اتجاه الجاذبية | ميزان الماء، وقياس الميل | **ميزان الماء** |
| التسارع الخطي (Linear acceleration) *برمجي* | حركتك فقط دون الجاذبية | معرفة: ثابت/يمشي/يجري، واكتشاف الحوادث | **مقياس النشاط** |
| عدّاد الخطوات (Step counter) | عدد الخطوات | اللياقة بأقل استهلاك للبطارية | **عدّاد الخطوات** |
| GPS | خط العرض والطول والسرعة والارتفاع | الخرائط والملاحة والقبلة ومواقيت الصلاة | **موقعي** + المسافة إلى مكة |
| حساس الضوء (Light) | شدة الإضاءة (lux) | السطوع التلقائي، والوضع الليلي، وراحة العين | **مقياس الإضاءة** |
| حساس القرب (Proximity) | جسم قريب من الشاشة | إطفاء الشاشة في المكالمة، والتحكم بالتلويح | **عدّاد بالتلويح** |
| البارومتر (Barometer) | ضغط الهواء (hPa) | الارتفاع والطوابق، وتسريع GPS، والطقس | **مقياس الارتفاع** |
| حرارة الجو (Ambient temperature) | °م (نادر في الجوالات) | حرارة الغرفة | **ميزان الحرارة** |
| الرطوبة (Humidity) | % (نادر في الجوالات) | راحة الجو | **مقياس الرطوبة** |
| الميكروفون | الصوت وشدته (dB) | المكالمات، والأوامر الصوتية، وقياس الضوضاء | **مقياس الضوضاء** |
| الكاميرا | الضوء على ملايين البكسلات | التصوير، وQR، وقراءة النصوص، والعدسة المكبّرة | **الكاميرا** (التقاط في الذاكرة فقط) |
| البصمة/الوجه (Biometrics) | نقوش البصمة | فتح الجوال، والبنوك، والدفع | **قفل البصمة** |

الشرح الكامل لكل حساس (طريقة عمله، وأمثلة من تطبيقات معروفة، والإذن المطلوب) موجود داخل التطبيق في
«دليل الحساسات»، ومصدره ملف [`sensors_app/lib/data/catalog.dart`](sensors_app/lib/data/catalog.dart).
ويعرض قسم **«حساسات جوالي»** كل الحساسات الموجودة فعلًا في جوالك مع مواصفاتها.

## 2) «رفيق»: التطبيق الشامل، وأي حساس يُستخدم وأين

| الميزة في «رفيق» | الحساسات المستخدمة | ماذا يفعل كل حساس فيها |
|---|---|---|
| 🔒 **قفل البصمة** | البصمة/الوجه | يفتح التطبيق، ويُقفل تلقائيًا عند الخروج منه |
| 🕋 **اتجاه القبلة** | GPS + متجه الدوران (تسارع + مغناطيس + جيروسكوب) | GPS: موقعك لحساب اتجاه مكة والمسافة إليها · المغناطيس: الشمال · الجيروسكوب: ثبات السهم · التسارع: وضع الجوال · ويُصحَّح الانحراف المغناطيسي لموقعك |
| 📿 **المسبحة الذكية** | القرب + التسارع | كل تلويحة فوق الجوال تُعدّ تسبيحة دون لمس · وهزّة قوية تصفّر العدّاد · واهتزاز مميز عند كل دورة |
| 🚶 **نشاطي اليومي** | عدّاد الخطوات + التسارع الخطي + البارومتر | الخطوات والمسافة · حالتك الآن (ثابت/تمشي/تجري) · الطوابق التي صعدتها |
| 📖 **بيئة القراءة** | الضوء + الميكروفون + الحرارة + الرطوبة | هل الإضاءة كافية؟ مع وضع ليلي تلقائي · هل المكان هادئ؟ (شدة الصوت فقط) · الحرارة والرطوبة إن وُجدت |
| 📏 **الميزان** | الجاذبية + الجيروسكوب | فقاعة الميزان وزوايا الميل · مؤشر «الجوال ثابت؛ القراءة موثوقة» |
| 🔍 **العدسة المكبّرة** | الكاميرا + الضوء | تكبير الخط الصغير حتى 8 أضعاف · ويعمل الكشاف وحده في الظلام |

داخل «رفيق» تعرض كل بطاقة الحساسات التي تستخدمها، وتعرض شاشة **«خريطة الحساسات»** العكس، أي أين يُستخدم كل
حساس. الكود في [`sensors_app/lib/companion/companion_app.dart`](sensors_app/lib/companion/companion_app.dart).

## الأمان في تطبيق الحساسات

| الإجراء | أين في الكود |
|---|---|
| **لا يملك إذن الإنترنت**، فلا يمكن أن تخرج أي قراءة من الجوال | `AndroidManifest.xml` |
| لا يُحفظ شيء: الصورة الملتقطة تبقى في الذاكرة ويُحذف ملفها المؤقت فورًا | `demos/other_demos.dart` |
| الأذونات تُطلب عند فتح الميزة فقط، مع شرح السبب (`PermissionGate`) | `widgets/common.dart` |
| أقل صلاحية: القبلة تكتفي بالموقع التقريبي، والميكروفون يقيس شدة الصوت فقط ولا يسجّل الصوت أبدًا | `LocationStream.kt` و`SoundLevelStream.kt` |
| كل الحساسات تتوقف عند الخروج من التطبيق (`onStop`)، فلا تعمل في الخلفية | `MainActivity.kt` |
| الجزء الأصلي يقبل فقط قوائم مسموحة: أنواع الحساسات وسرعات القراءة والأذونات (حساسات الجسم مستبعدة) | `SensorStream.kt` و`PermissionRequester.kt` |
| النسخ الاحتياطي معطّل (`allowBackup=false` و`dataExtractionRules`) | `AndroidManifest.xml` |
| منع HTTP غير المشفّر والشهادات التي يضيفها المستخدم | `res/xml/network_security_config.xml` |
| إزالة إذن التخزين الخارجي الذي تضيفه مكتبة الكاميرا (`tools:node="remove"`) | `AndroidManifest.xml` |
| البصمة لا تغادر الشريحة الآمنة، و«رفيق» يُقفل عند الخروج منه | `companion_app.dart` |
| نسخة الإصدار مُصغَّرة ومُعمّاة (R8 + `--obfuscate`)، و`debuggable=false` | `build.gradle.kts` و`ci.yml` |
| مفتاح التوقيع من أسرار GitHub وليس من المستودع | `build.gradle.kts` |
| minSdk 29 (أندرويد 10+) لضمان الأذونات الحديثة والتحديثات الأمنية | `build.gradle.kts` |
| مكتبات قليلة ورسمية فقط (`camera` و`local_auth` من فريق Flutter)، والباقي كود أصلي دون مكتبات | `pubspec.yaml` |
| **فحص آلي** للكود ولملف APK الناتج بأداة mvscan في كل بناء، ويفشل البناء عند أي ثغرة | `.github/workflows/ci.yml` |

## 3) mvscan: كاشف الثغرات البرمجية في تطبيقات الجوال

أداة Python لا تحتاج أي مكتبات خارجية. تفحص:

- **مجلد مشروع**: أندرويد (Java/Kotlin) وFlutter (Dart) وiOS (Swift/Objective-C) وReact Native (JS/TS).
- **ملف APK / XAPK / APKS**: تفك ترميز `AndroidManifest.xml` الثنائي، وتقرأ نصوص `classes.dex` والمكتبات `.so`.
- **ملف IPA** (iOS): تفحص `Info.plist` والملف التنفيذي.
- **التطبيقات المثبتة في جوالك** عبر USB (`--adb`).

```bash
cd mobile_vuln_scanner
python3 -m mvscan /path/to/project                 # مشروع
python3 -m mvscan app.apk --format html -o report.html   # تقرير HTML
python3 -m mvscan --adb                             # كل التطبيقات المثبتة في الجوال المتصل
python3 -m mvscan --adb --package com.example.app   # تطبيق واحد
python3 -m mvscan . --min-severity medium --fail-on high  # في CI
```

لفحص تطبيقات جوالك: فعّل «خيارات المطوّر» ثم «تصحيح USB»، ووصّل الجوال بالكمبيوتر، وثبّت
[Android platform-tools](https://developer.android.com/tools/releases/platform-tools) (أمر `adb`).

**ماذا يكشف؟** أكثر من 55 قاعدة في 10 فئات: المفاتيح والأسرار المكتوبة في الكود، والاتصال غير المشفّر،
وتجاوز التحقق من شهادات TLS، وثغرات WebView، والتشفير الضعيف، والتخزين غير الآمن، وحقن SQL والأوامر،
والمكوّنات المكشوفة لتطبيقات أخرى، وإعدادات `AndroidManifest` و`Info.plist` الخطرة، وطباعة الأسرار في السجل،
وثغرات PendingIntent والبث. القائمة الكاملة مع الحلول في
[`mobile_vuln_scanner/README.md`](mobile_vuln_scanner/README.md).

أداة الفحص نفسها مكتوبة بأمان: لا تفك الأرشيفات على القرص (فلا zip-slip)، ولها حدود للحجم ضد قنابل الضغط،
وترفض XML الذي يحتوي DTD، ولا تتبع الروابط الرمزية، وتمرّر أوامر adb كقائمة بعد التحقق من أسماء الحزم،
وتخفي الأسرار المكتشفة في التقارير، وتهرّب كل نص في تقرير HTML.

## البناء والتطوير

```bash
# التطبيق
cd sensors_app
flutter pub get && flutter analyze && flutter test
flutter build apk --release --split-per-abi --obfuscate --split-debug-info=build/symbols

# أداة الفحص
cd mobile_vuln_scanner
pip install pytest && python3 -m pytest -q
```

### مفتاح التوقيع

بدون إعداد، تُوقَّع النسخ بمفتاح debug لتسهيل التجربة. لنشر حقيقي (مثل Google Play) أنشئ مفتاحًا:

```bash
keytool -genkeypair -v -keystore release.jks -keyalg RSA -keysize 4096 -validity 10000 -alias sensors
base64 -w0 release.jks   # انسخ الناتج
```

ثم أضف في **Settings ← Secrets and variables ← Actions** هذه الأسرار:
`SIGNING_KEYSTORE_BASE64` و`SIGNING_KEYSTORE_PASSWORD` و`SIGNING_KEY_ALIAS` و`SIGNING_KEY_PASSWORD`.
**لا ترفع ملف المفتاح إلى المستودع أبدًا** (ملف `.gitignore` يمنع ذلك).
